
# 11月分進捗
## 操作方法
ADで移動。スペースでジャンプ。  
Jでアンカー射出
Kで壁に刺さったアンカーにテレポート
敵にアンカーが当たるとロックオンされ、Lを押すと一括破壊
ゴールに到達するとクリア

## その他
